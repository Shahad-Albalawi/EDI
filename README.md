# EDI – Explore / Develop / Improve

## Overview
**EDI** is an AI-powered sports coaching platform that helps athletes train, improve, and get discovered.  
This version focuses on the **Coach Dashboard**, where coaches can evaluate players’ performance using AI insights.

---

## Technologies
- **Python** (Analysis Module)  
- **OpenCV**, **MediaPipe**, **NumPy**  
- **HTML/CSS/JS** (Web Module)  

---

## Coach Dashboard

The **Coach Dashboard** allows coaches to:
- Analyze player movements and dribbling skills
- Track performance metrics: passes, dribbles, speed
- View AI-powered visual feedback for training improvements
